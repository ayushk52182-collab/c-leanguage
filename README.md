# Learn with Aayush | Interactive 3D C, Python & Striver DSA Academy

An immersive 3D interactive learning ecosystem engineered by Aayush Singh for mastering C Language, Python, and the complete Striver A2Z Data Structures & Algorithms sheet.

## Tech Stack
- **Framework**: React 18 + Vite
- **3D Engine**: Three.js + React Three Fiber + Drei
- **Animations**: Framer Motion + GSAP
- **Icons**: Lucide React
- **Design System**: Neon Cyberpunk / Warm Obsidian Design System (Full Light & Dark Mode)

## Getting Started

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Run Tests / CI Verification
```bash
npm test
```

## Features
- **Striver A2Z DSA Sheet**: Comprehensive DSA curriculum with video solutions, problem statements, and automatic progress tracking.
- **Interactive Visualizers**: Real-time interactive animations for Arrays, Linked Lists, Stacks, Queues, Trees, and Graphs.
- **In-Browser C IDE**: Live practice zone with sample codes, error tracking, and syntax highlighting.
- **Interactive Session Auth**: Google Account sign-in/up dialog with unique email protection and online status indicator.
- **Multi-Theme Engine**: Seamless switching between Cyberpunk Dark and Clean Sunlight Light modes.
